# TwixxerChat для Android

Это проект, из которого GitHub сам собирает установочный файл приложения (APK). Ничего устанавливать на компьютер не нужно.

## Как получить APK

1. Создайте на GitHub новый репозиторий (например, `twixxer-android`). Для бесплатной сборки он должен быть **публичным**.
2. Загрузите в него все файлы из этой папки: **Add file → Upload files**, перетащите содержимое (вместе с папкой `.github`).
   Если папка `.github` не загрузилась, создайте файл вручную: **Add file → Create new file**, имя `.github/workflows/build-android.yml`, и вставьте в него содержимое одноимённого файла из архива.
3. Откройте вкладку **Actions**. Если GitHub просит разрешить запуск, нажмите зелёную кнопку согласия.
4. Выберите слева **Сборка Android APK** и нажмите **Run workflow**. Сборка идёт примерно 10–15 минут.
5. Когда рядом с запуском появится зелёная галочка, откройте его и внизу страницы, в разделе **Artifacts**, скачайте `TwixxerChat-debug-apk`.
6. Распакуйте архив, получится файл `app-debug.apk`. Передайте его на телефон (любым мессенджером, по USB, через облако) и откройте.
7. Android спросит разрешение «Установка из неизвестных источников» для программы, из которой вы открыли файл. Разрешите и установите.

## Вход и сервер

- Войти можно по логину и паролю. Вход через Google в приложении не работает: Google запрещает его во встроенных браузерах.
- По умолчанию приложение подключается к серверу `https://twixxer657-twixxer-chat.hf.space`.
- Если сервер не открывается, наверху появится красная полоса «Нет соединения с сервером». Нажмите **Сменить сервер** и введите новый адрес (например, `https://chat.example.ru`). Пересобирать приложение для этого не нужно. Пустое поле вернёт адрес по умолчанию.

## Как обновить приложение

1. Замените файл `src/index.html` новой версией сайта и сохраните изменения (commit).
2. GitHub пересоберёт APK сам, или запустите сборку вручную, как в пункте 4.
3. Отладочная сборка подписывается новым временным ключом каждый раз, поэтому Android не даст установить её поверх старой. Сначала удалите старое приложение, затем установите новое (вход потребуется заново, переписка хранится на сервере и не пропадёт).

Чтобы обновлять поверх прежней версии, настройте постоянную подпись (ниже).

## Постоянная подпись (по желанию)

На компьютере с установленной Java выполните (запомните пароль, он должен быть **одинаковым** для хранилища и ключа):

```
keytool -genkeypair -v -keystore twixxer.jks -alias twixxer -keyalg RSA -keysize 2048 -validity 10000
```

Закодируйте файл (Linux/macOS: `base64 -w0 twixxer.jks`; Windows PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("twixxer.jks"))`) и добавьте в репозитории **Settings → Secrets and variables → Actions → New repository secret** три секрета:

- `ANDROID_KEYSTORE_B64`: закодированный файл;
- `ANDROID_KEYSTORE_PASSWORD`: пароль;
- `ANDROID_KEY_ALIAS`: `twixxer`.

После этого сборка дополнительно выдаёт подписанный `TwixxerChat-release-apk`, который можно ставить поверх старой версии. **Файл `twixxer.jks` храните в надёжном месте и никому не показывайте**: если он потеряется, обновлять приложение поверх станет нельзя.

## Что пока не работает

- **Уведомления при закрытом приложении.** Звук и значки есть, пока приложение открыто. Полноценные push-уведомления будут отдельным шагом.
- **Ссылки-приглашения** (`...?invite=...`) открываются в браузере, а не в приложении.
- **Значки и шрифты** подгружаются с Google Fonts. Если они недоступны, вместо значков могут появиться подписи.

## Если сборка упала

Откройте запуск с красным крестиком, найдите шаг с ошибкой и отправьте последние 30–40 строк лога: так проще всего понять причину. Если экранная клавиатура ведёт себя странно (поле ввода уезжает), пришлите скриншот и модель телефона.
